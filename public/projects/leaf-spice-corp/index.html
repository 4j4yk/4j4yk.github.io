Shopify E-Commerce Store Project: “The Leaf & Spice Co.”#

Business Owner’s Vision#

I’m starting a premium online store called “The Leaf & Spice Co.”, specializing in organic, hand-crafted paan blends, mouth fresheners (mukhwas), and herbal teas. The store will target health-conscious, modern consumers interested in traditional Indian products with a luxurious, global feel.

Shopify E-Commerce Project: The Leaf & Spice Co.

This project delivers a premium Shopify store featuring organic paan blends, mouth fresheners, and herbal teas. Managed using Agile methodology with Jira and GitHub.

Agile Epics#

1. Store Setup & Configuration#

  • Create Shopify store
  • Connect domain, setup payments
  • Add legal pages (Privacy, Refund, Terms)

2. Branding & Theme Customization#

  • Design logo and define brand identity
  • Customize Shopify theme (colors, fonts, homepage layout)

3. Product Management#

  • Upload products via CSV
  • Create collections and filters
  • Implement custom product template

4. Checkout, Shipping & Fulfillment#

  • Configure payment gateway
  • Set up shipping zones and rates
  • Integrate fulfillment and tracking

5. Marketing, SEO & Engagement#

  • Optimize SEO and metadata
  • Connect Google Analytics and Meta Pixel
  • Set up email marketing (Klaviyo)

6. Advanced Features (Optional)#

  • Add subscriptions with Recharge
  • Build a gift box builder UI

7. Testing & Go-Live#

  • QA all flows (cart, checkout, mobile)
  • Go live with a password-free store

Boards#

This project uses:

  • Scrum Board (in Jira): Backlog → To Do → In Progress → Done link

Tech Stack#

  • Platform: Shopify
  • Theme: Taste (customized)
  • Marketing: -
  • Shipping: default
  • Optional: Recharge (subscriptions), Loox (reviews)
