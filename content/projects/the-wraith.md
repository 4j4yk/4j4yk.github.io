What if a pirate ship could jump between dimensions, and what if somebody tried to sell it online?

**The-Wraith** is my demo storefront for exactly that strange idea. The ships, prices and charter experience are fictional. The project is real, though, and I use it to explore where AI-assisted development helps and where human review is still needed.

![The-Wraith dimension-traveling pirate ship storefront](https://raw.githubusercontent.com/4j4yk/The-Wraith/main/public/product-ship.png)

## What is in the project

- A responsive storefront generated initially with **v0**
- Landing, product and fictional charter views
- A **Rift Registry** for range, crew, jump-time and cannon specifications
- Mobile scrolling improvements without changing the compact desktop experience
- A clearly fictional charter manifest which collects and sends no personal or payment information
- GitHub-based review and automatic Vercel preview and production deployments
- Basic production analytics and release verification

## Technology

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Vercel Analytics
- v0 by Vercel

## Why I built it

This is not a real commerce service. It is a small place where I can try AI product ideation, generated interfaces, code review, responsive design and deployment as one continuous workflow.

The project is also agent-maintained, but with boundaries. Changes should stay focused and reversible, work gets verified locally, user trust is protected, and pushing or deploying requires explicit approval.
